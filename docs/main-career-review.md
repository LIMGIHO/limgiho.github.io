## 최근 사실·측정 범위

- 팀 3인 리드·주간 리뷰, 외부 호출 75개 공동 분석·구현, OOM 공동 분석과 본인의 결론 도출, API/Worker·CI 단독 기여를 구분했다.
- Redis 락 획득 후 공유 세션 재조회로 설명했다. Promise 공유 경로를 함께 사용한다고 쓰지 않았으며, 소유권·갱신은 예방적 보강으로 표시했다.
- 삼성 마감의 계산·입력 변환·차지 데이터 구성 분리와 직접 구현·리뷰 공유를 반영했다. 내부 모듈명·사내 주소·IP·토큰·원본 코드는 공개 본문에 넣지 않았다.
- 하루 BL 약 800~900건과 반복 API 호출 수를 구분했다. 네트워크 60~70Mbps→대체로 5Mbps 미만은 운영 관측이다.
- 2026-10-02 추가한 API 로그 기능은 초기 약 반나절, 시간당 8,000회·분당 최대 550회 관측으로 한정했다. 인증 감소 효과·장기 안정성은 미확인이다.
- OOM의 54,565행→500행·무한스크롤 조치, 서버 중단 없음·전체 메모리 30~40%는 운영 결과다. 480회·8라운드, heapUsed 2.8MB·peak RSS 약 122MB는 별도 모사 실험이다.
- Worker의 HTTP 응답 대기와 DB 상태·큐 재시도·락의 책임을 구분했다. 외부 부수효과와 완료 기록 간의 중복 실행 가능성, 코드 예외 메일과 배치 최종 실패 알림 부재를 반영했다.
- 9월 buildx·러너·캐시, 단일 파이프라인의 앱별 변경 경로 실행 조건을 반영했다. API 테스트 잡 3분27초→2분25초는 전후 로그다.
- 삼성 NERP 월 1,200시간은 원본 산정치이며 산정 근거 미확인을 표시했다. 글로벌 자동화의 다른 프로젝트 수치와 합치지 않았다. 과거 통관 월 200시간 수치는 쓰지 않았다.

## 가독성 보완 · 2026-10-04

사용자 피드백에 따라 OOM 도입 문단의 RSS·heapUsed·네이티브 메모리 표현을 프로세스 전체 메모리와 JavaScript 객체 메모리의 차이, 조회 라이브러리 내부 사용에 대한 가설로 풀어 썼다. 모사 실험 수치에는 GC·heapUsed·peak RSS가 가리키는 대상을 함께 표기했다. 가설 수정 과정과 측정 범위·수치는 유지했다.

## 문장 정리 · 2026-10-09

사용자가 지정한 `gudgeon/docs/application-drafts/toss-securities-prequestions.md`와 원본 PDF를 대조해 메인 경력기술서를 다듬었다. 실제 수행한 일과 본인 역할을 쓰고(Fact), 각 사례의 문제·조치·결과에 집중하며(Focus), 규모나 개선 결과를 설명하는 수치를 남겼다(Figures).

- 글로벌 연동: 운송장 상태 나열과 BL/API 건수 구분 문장을 삭제했다. 하루 약 800~900건은 다루는 운송장 규모로, 75개 호출·12종 흐름은 구현 범위로 각각 서술했다. Redis 공유 세션과 락 획득 후 세션 재확인, 운영 네트워크 사용량 60~70Mbps→대체로 5Mbps 미만을 남겼다.
- 메모리 장애: 제목을 `Node.js API 서버 메모리 장애 개선`으로 바꿨다. 54,565행은 `수만 건`으로 정리하고 500건 단위 조회·무한스크롤, 서버 전체 메모리 30~40%, 해당 장애 미재발을 남겼다. 별도 응답 처리 모사 실험은 가공·직렬화 중 사용량 증가와 GC 후 힙 누적 패턴 미확인으로 설명했다. 전체 시스템의 메모리 누수가 없다고 확대하지 않았다.
- 최근 보충 내용: 삼성 마감의 추상화 사례와 API 호출 로그의 반나절 관측 수치, 모사 실험의 480회·8라운드·2.8MB·122MB는 본문에서 제외했다. 위의 2026-10-04 검토 기록과 기존 회고에는 근거를 보존한다.
- CI/CD: 2026년 9월 개선과 3분27초→2분25초를 남기고 측정 범위를 `개선 전후 로그 기준`으로 서술했다. 별도 통제 실험으로 표현하지 않았다.
- 원본 PDF: 업무·개인 프로젝트와 기간·역할·성과를 보존했다. 통관 검토 시간의 산식 설명은 원본의 월 100건 기준 약 8.3시간으로 줄였다. RPA 월 1,200시간은 `기존 경력기술서 산정치`로 표시했다. 기존 산정 근거 미확인 상태를 새로 검증했다고 주장하지 않는다.
