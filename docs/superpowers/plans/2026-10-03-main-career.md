# 메인 전체 경력기술서 구현 계획

**Goal:** `docs/sol-main-career-prompt.md`의 확정 요구사항에 따라 메인을 전체 경력기술서로 완성한다.

**Architecture:** 기존 Jekyll 메인 레이아웃과 GIHO 런타임을 유지한다. `_data/main_career.yml`에 전체 경력과 추가 개선 사례를 편집하고, 레이아웃에서 역할·기술·성과를 구분한다. 표지와 본문 바로가기, 스크롤 목차는 기존 동작을 사용한다. 지원 페이지도 참조하는 기존 `_data/resume.yml`은 보존한다.

**Tech Stack:** Jekyll / Liquid / YAML / CSS / Node test / Playwright CLI.

## 제약

- 지정된 gudgeon worktree에서 작업한다. 기존 미추적 파일과 지원용 데이터·페이지·PDF·스크립트는 직접 수정하지 않는다.
- 직무는 백엔드 개발자. 지원 동기·지원 회사·검토본 표기를 넣지 않는다.
- 기존 PDF 업무 10개·개인 3개를 보존하고 원본 PDF 파일은 유지한다. 메인 PDF 링크는 제거한다.
- 운영 관측, 모사 실험, 산정치를 구분한다. 내부 주소·호스트·소스·토큰을 게시하지 않는다.
- 외부 웹 링크 및 포트폴리오는 새 탭으로, 목차는 현재 페이지 안에서 이동한다.
- 배포하지 않는다.
