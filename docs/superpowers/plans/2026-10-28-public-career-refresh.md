# 공개 경력기술서·포트폴리오 사실관계 갱신

사용자 승인: 지원서 v4와 대조한 수정안을 전체 반영하고 GitHub Pages까지 배포.

## 범위
- `_data/main_career.yml`: 통합 완료 기간, 본사 연동 기간, 통관 검증·프리알럿, OOM 분석, 포상 정정. 본사 연동 추산과 NERP 성과를 구분하고 호출 감소 사례 추가.
- `_data/career_profiles.yml`: 공개된 프로필의 덮어쓰기 문구도 동일 사실로 정정.
- `_data/portfolio.yml`, `_data/portfolio_profiles.yml`: 통합 완료·현재 업무 분리, 대표 지표를 해당 항공수출 화면의 일일 호출 약 29% 감소로 변경. 산정표는 본사 자동화 상세에 보존하고 추산임을 명시. 통관 설명과 운영 개선 사례 보강.
- `_includes/portfolio/automation.html`: 데이터에 담긴 운영 개선 설명을 기존 스타일로 표시.
- 오래된 PDF는 수정·삭제하지 않고 기본 포트폴리오에서 링크를 숨겨 최신 웹 경력기술서로 안내.
- `_data/resume.yml`·`_config.yml`의 과거 지원서용 데이터, 제출용 PDF, 사용자의 기존 미커밋 변경은 이번 커밋에서 제외.

## 검증·배포
1. 기존 렌더링 검사에서 달라지는 기간·문구·항목 수를 갱신.
2. 일반 및 baseurl Jekyll 빌드, 경력/프로필/링크/익명화 검사.
3. 데스크톱·모바일 화면에서 긴 지표·본문 줄바꿈과 수평 넘침 확인.
4. 선택 파일만 커밋하고 origin/main에 push. Pages 워크플로 성공과 실제 공개 URL의 변경 문구 확인.

## 수치 범위
- 29% = (7,000-5,000)/7,000. 사용자 제공 일일 관측치이며 특정 항공수출 업무 화면 기준. 전체 시스템 또는 개별 개선의 독립 효과로 확대하지 않음.
- 약 94%는 제공된 10/26 호출의 문서·템플릿 검색 구성비.
- 약 1,200시간은 본사 업무 자동화의 부서별 처리량·작업 시간 추산. 삼성 NERP 단독 성과나 실측으로 표현하지 않음.


## 진행 중 사용자 정정 반영
- 호출 모니터링을 2025.06부터 개발한 것으로 보이는 기간 오류 정정: 확인된 호출 분석·개선 시점인 2026.10만 표시.
- 첫 문장에 본사 시스템 첨부 문서 목록·운송장 템플릿 조회라는 요청의 업무 맥락 추가.
- 지원서 v5에 같은 정정과 주간 코드 리뷰·React 운영 화면 구현 근거 보완. 지원서 및 전략 검토 파일은 기존 작업 디렉터리에 보존하고 공개 배포 커밋에는 포함하지 않음.


## 검증 결과
- 일반·baseurl 빌드 성공, 경력/프로필/링크/기존 화면 동작 검사 54개 통과.
- 포트폴리오 원본·렌더링 익명화 검사 통과.
- 데스크톱·모바일에서 변경 지표와 본문 확인. 모바일 문서 너비 390px로 수평 넘침 없음.
- YAML에서 2026.10이 실수로 해석돼 2026.1로 표시되던 문제를 문자열 표기로 수정하고 렌더링 결과 확인.
- 지원서 v5 A4 3페이지 시각 확인. 기존 지원서 버전 보존.
