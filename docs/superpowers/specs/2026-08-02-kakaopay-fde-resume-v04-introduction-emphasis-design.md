# 카카오페이 FDE 이력서 v04 소개·강조 디자인

## 범위

- 첫 페이지의 `경력 요약` 제목을 `소개`로 변경한다.
- 소개 세 문단의 사실과 문장은 바꾸지 않는다.
- 채용 담당자가 빠르게 훑을 때 남아야 할 역할·규모·업무 방식만 강조한다.
- HTML과 CSS만 수정하며 PDF는 생성하지 않는다.

## 강조 기준

- 문단별 강약을 두고 핵심 구절만 `<strong>`으로 표시한다.
- 첫 문단은 업무 관점, 둘째 문단은 통합 규모와 글로벌 시스템, 셋째 문단은 AI 활용 방식과 현재 역할을 강조한다.
- 본문 색상은 유지하고 굵기만 높여 문장 흐름을 방해하지 않도록 한다.
- 다른 섹션과 PDF 파일은 변경하지 않는다.

## 검증

- 제목이 `소개`로 표시되는지 확인한다.
- 강조 구절이 문장의 일부에만 적용되는지 확인한다.
- HTML 검증 스크립트를 통과하는지 확인한다.
- PDF 생성 스크립트는 실행하지 않는다.
