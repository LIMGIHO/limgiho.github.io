# 당근 지원용 경력기술서와 포트폴리오

사용자가 지정한 `/daangn/`에 상세 경력기술서, `/daangn/portfolio/`에 프로젝트 포트폴리오를 제공한다. 기존 Jekyll 레이아웃에 지원용 프로필을 추가해 콘텐츠와 링크를 선택한다.

경력기술서는 최신 메인 데이터를 사용하되 삼성 NERP RPA 프로젝트를 제외한다. 웹 통합 프로젝트의 C# 입력 자동화·공용 라이브러리 문장과 NestJS·컨테이너 전환 문장을 제거한다. 다른 프로젝트의 기술 설명은 유지한다.

흰 배경에 당근 주황색을 사용한다. 포트폴리오의 네 가지 대표 수치는 제출용 v14 PDF의 시스템 15종 이상, 회선 사용량 60~70Mbps에서 5Mbps 미만, 통관 검토 8분에서 3분, 전체 파이프라인 12분에서 6분으로 구성한다.

두 페이지는 서로 연결하고 제출용 PDF를 제공한다. v14 PDF의 기존 경력기술서·포트폴리오 링크만 새 경로로 수정해 v15로 저장한다. PDF의 본문과 렌더링은 원본과 같아야 한다.

실제 Jekyll 빌드에서 경로·콘텐츠 선택·교차 링크·PDF·baseurl을 검증하고 데스크톱과 모바일에서 화면을 확인한 뒤 기존 GitHub Pages 배포 흐름으로 공개한다.
