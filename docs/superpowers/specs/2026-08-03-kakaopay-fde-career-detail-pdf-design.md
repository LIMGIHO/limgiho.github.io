# 카카오페이 FDE 상세 경력기술서 PDF 설계

## 목표

Google Docs 변환본을 사용하지 않고 HTML/CSS에서 직접 4페이지 A4 상세 경력기술서를 생성한다. 현재 v04 이력서와 같은 시각 체계를 사용하며, 완료한 결과와 현재 진행 중인 일을 명확히 분리한다.

## 산출물

- 원본 HTML: `resumes/kakaopay-fde-career-detail/index.html`
- 전용 스타일: `resumes/kakaopay-fde-career-detail/resume.css`
- 빌드 스크립트: `scripts/build-kakaopay-fde-career-detail-pdf.sh`
- 검증 스크립트: `scripts/verify-kakaopay-fde-career-detail.py`
- 공개 PDF: `assets/resume/lim-giho-kakaopay-fde-career-detail.pdf`
- 버전 보존본: `output/pdf/versions/lim-giho-kakaopay-fde-career-detail-v02.pdf`

기존 Google Docs PDF는 `v01`로 유지한다. v04 이력서가 사용하는 공개 URL은 유지하므로 링크 교체는 필요하지 않다.

## 문서 구성

- 이름, 연락처, GitHub
- 경력기술서 소개
- KWE 역할과 담당 범위
- 프로젝트 상태가 보이는 경력 타임라인
- 통합 플랫폼과 글로벌 물류 운영 자동화

### 2페이지 — KWE 구축·운영 경험

- GitLab CI/CD와 컨테이너 배포 체계
- AI 에이전트 기반 MVP 개발
- 온프레미스 LLM 문서 구조화와 RAG 검색
- 완료한 결과와 현재 고도화 범위를 각각 표기

### 3페이지 — KWE 완료 프로젝트와 ILJIN 주요 프로젝트

### 4페이지 — ILJIN 프로젝트·개인 프로젝트·기술

- 댓글 필터, HealthDog, 액션독과 공개 링크
- 기술 스택

## 프로젝트 상태와 시제

프로젝트 기간과 완료 여부를 분리한다. `현재`라는 날짜만으로 미완성처럼 보이지 않게 상태 라벨과 문장 시제를 함께 사용한다.

| 프로젝트 | 상태 | 표현 원칙 |
| --- | --- | --- |
| 통합 플랫폼·물류 운영 자동화 | 운영·확장 중 | 구축·적용 결과는 과거형, 추가 대상과 운영 개선만 현재형 |
| GitLab CI/CD·컨테이너 배포 | 구축 완료·운영 중 | 전환·차단·추적 체계는 완료형, Runner 분리는 후속 계획 |
| AI 에이전트 기반 MVP | 적용·고도화 중 | 이미 적용한 검증 방식은 완료형, 적용 범위 확장은 현재형 |
| 온프레미스 LLM·RAG | 개발 중 | 구현·검증한 기능과 남은 고도화를 구분 |
| 삼성 전세기 프로젝트 | 완료 | 분석·기능 구현·자동검증 결과를 완료형으로 표기 |
| 세금계산서 리뉴얼 | 완료 | 이관·검증·연동 결과를 완료형으로 표기 |
| ILJIN 프로젝트 | 완료 | 종료 기간과 결과를 완료형으로 표기 |

`하고 있습니다`의 반복을 피하고 `구축했습니다`, `운영에 적용했습니다`, `검증했습니다`처럼 전달된 결과를 먼저 쓴다. 진행 중인 내용은 각 프로젝트 마지막 문장에서만 `확장하고 있습니다`, `고도화하고 있습니다`로 제한한다.

## 디자인

- v04 이력서의 노란색 상단선, 검은 제목, 회색 보조 정보, 얇은 구분선을 재사용한다.
- 프로젝트마다 상태 라벨, 기간, 기술 스택, 배경·구현·결과를 같은 위치에 둔다.
- 상태 라벨은 장식용 배지가 아니라 작은 텍스트 라벨로 사용한다.
- 본문은 최소 9pt 이상을 유지하고 페이지마다 푸터와 페이지 번호를 표시한다.
- 내부 용어는 역할을 먼저 설명하고 `UFS+`는 상세 프로젝트에서 한 번만 병기한다.

## 검증

- HTML에 모든 필수 프로젝트와 상태가 존재하는지 확인한다.
- `UFS+`는 한 번만 등장하고 Google Docs URL은 포함하지 않는다.
- 완료 프로젝트 본문에 불필요한 현재형이 반복되지 않는지 확인한다.
- PDF가 4페이지 A4인지, 페이지별 텍스트가 잘리지 않는지 검사한다.
- 개인 프로젝트 링크와 연락처 링크가 PDF에 포함되는지 확인한다.
- 각 페이지를 PNG로 렌더링해 겹침, 잘림, 지나친 여백과 글자 크기를 육안 검수한다.

## 범위 밖

- v04 이력서의 본문과 3페이지 구성은 변경하지 않는다.
- Google Docs 원본은 삭제하지 않고 편집 참고용으로 유지한다.
- 확인되지 않은 수치나 프로젝트 성과는 추가하지 않는다.
