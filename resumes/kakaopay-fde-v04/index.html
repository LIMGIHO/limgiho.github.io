온프레미스 LLM 기반 문서 처리와 담당 업무 검색

Local LLM · OCR · Structured JSON · Vitest · On-premise

문제
수출신고필증은 벤더마다 형식이 달랐고 스캔본에는 텍스트가 없었습니다. 담당 업무 검색도 표현이 달라지면 후보를 찾지 못했습니다. 문서를 외부로 보낼 수 없어 사내에서 운영하는 모델만 사용했습니다.
구현
의미 해석은 LLM에 맡기되 페이지 묶기, 호출, 병합, 산술 검증은 코드로 처리했습니다. 업로드와 추출을 분리해 일부 추출이 실패해도 작업 전체가 중단되지 않게 했고, 텍스트가 없는 문서만 OCR을 거칩니다.
안전장치
실제 PDF로 회귀 테스트를 돌려 문맥 손실과 OCR 오인식을 확인했습니다. 검색 결과가 불확실하면 기존 검색으로 되돌리고, 로그에는 문서 원문과 OCR 전문을 남기지 않습니다. 최종 판단은 담당자가 하는 human-in-the-loop 구조입니다.
